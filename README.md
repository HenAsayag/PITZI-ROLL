# PITZI ROLL · פיצי רול

משחק מרוץ גולות תלת־ממדי בדפדפן בהשראת Hamsterball. הכול מקורי: אוגר בשם פיצי מתגלגל בכדור שקוף נגד השעון. המשחק חלק מ־HEN'S ARCADE.

## מה בחבילה
| תיקייה | תוכן |
|---|---|
| `MASTER_PROMPT.md` | הפרומפט לבנייה ב־one-shot. מדביקים ל־Claude יחד עם התיקייה |
| `docs/research.md` | מחקר על המשחק המקורי וההחלטות שנגזרו ממנו |
| `levels/levels.json` | 8 מרוצים כשרשרת סגמנטים, כולל זמנים ומדליות |
| `levels/previews/` | מפת מבט־על ופרופיל גובה לכל מרוץ (`_overview.png` מציג את כולם) |
| `assets/textures/` | 32 טקסטורות: רצפות ל־7 ערכות נושא, קירות, שמיים, פדים ומשטחים |
| `assets/sprites/` | חלקיקים: כוכבי סחרחורת, ניצוץ, אבק, רסיס זכוכית, צל |
| `assets/ui/` | לוגו, פיצי ב־3 הבעות, פיצי בכדור, favicon (SVG + PNG) |
| `assets/icons/` | 17 אייקונים ומדליות (SVG + PNG) |
| `assets/sfx/` | 22 אפקטים + לופ מוזיקה (WAV) |
| `assets/fonts/` | Rubik עם תמיכה בעברית (רישיון OFL) |
| `tools/` | הסקריפטים שיצרו את הכול. אפשר להריץ שוב ולשנות |

## איך משתמשים
1. פותחים שיחה חדשה עם Claude, מעלים את התיקייה (או את `levels.json` וצילום של `assets/`) ומדביקים את `MASTER_PROMPT.md`.
2. שומרים את `index.html` ואת `game.js` שחוזרים ליד `assets/` ו־`levels/`.
3. מריצים שרת סטטי: `npx serve .` ופותחים בדפדפן.

## עריכת מסלולים
במשחק יש 4 מסלולים: רשת הניאון, משטח הקרח, ושני מסלולים חדשים וקשים יותר, מסלול העננים וגמר המפעל. עורכים את `LEVELS` ב־`tools/make_levels.mjs` ומריצים `node tools/make_levels.mjs`. הסקריפט מחשב את כל התנוחות, הזמנים והמדליות, ובודק שהמסלול חוקי: יש התחלה וקו סיום, יש צ'קפוינט, כל פער אפשר לחצות ואין חפיפות. (`tools/make_levels.py` הוא הגרסה המקורית עם 8 המסלולים ותצוגות מקדימות.)

## לשחק מהטלפון (GitHub Pages)
1. ב־GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, בוחרים `main` ו־`/ (root)` ולוחצים **Save**.
2. אחרי דקה־שתיים המשחק זמין בכתובת: **https://henasayag.github.io/PITZI-ROLL/**
3. בטלפון המשחק עובד רק לרוחב (במצב לאורך מופיע "סובבו את הטלפון"). באנדרואיד לוחצים "מסך מלא ויאללה" במסך הפתיחה. באייפון אין מסך מלא בדפדפן, אז לוחצים "המשך"; למסך מלא באייפון: **שתף ← הוספה למסך הבית**, ופותחים מהאייקון.

## טבלת שיאים משותפת (Firebase, חינם)
הפרויקט `pitzi-roll` כבר מחובר דרך `leaderboard-config.js`. בלי סיסמאות: כל מכשיר נכנס אנונימית ותופס שם פנוי (למשל Hen), והשם נשאר שלו בדפדפן הזה.
צריך לעשות פעם אחת בקונסולה של Firebase:
1. **Build → Authentication → Sign-in method → Anonymous → Enable → Save**.
2. **Build → Firestore Database** (אם עוד לא נוצר: Create database, production mode) **→ Rules**: מדביקים את התוכן של `firestore.rules` ולוחצים **Publish**.

עד שזה מוכן, מסך בחירת השם מציג "לשחק בלי חיבור" והמשחק עובד רגיל.
אם מישהו איבד את השם שלו (מחק נתוני גלישה / החליף דפדפן), אפשר לשחרר אותו ב־Firestore: מוחקים את `names/<השם באותיות קטנות>` ואת `players/<uid>` שלו.
ריצות במצב מראה ודילוגי מפתח (Shift+N) לא נספרים.
