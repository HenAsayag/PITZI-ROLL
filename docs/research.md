# מחקר: Hamsterball, ומה לוקחים ממנו ל־PITZI ROLL

## המשחק בקצרה
- **Hamsterball** פותח ע"י Raptisoft ויצא ל־Windows ב־8 בפברואר 2004 (גרסת PS3 ב־2010). הוא זכה בפרס "Computer Downloadable Game of the Year" בטקס ה־Interactive Achievement Awards השביעי.
- הוא בנוי כמו Marble Madness: מרוץ נגד השעון ב־15 מסלולים, ובמקום גולה יש אוגר בתוך כדור פלסטיק שקוף.
- הגרסה המקורית כללה 12 מרוצים. Hamsterball Gold הוסיף את Neon Race, Glass Race ו־Impossible Race.

## לולאת המשחק (מה שהופך אותו לממכר)
| מכניקה | איך זה עובד במקור | מה לוקחים |
|---|---|---|
| **זמן כמשאב יחיד** | בכל מרוץ נוסף זמן קבוע לשעון, ומה שנשאר עובר למרוץ הבא. כשהזמן נגמר המשחק נגמר | כן, זה הליבה |
| **נפילה = עונש זמן** | נפילה קצרה משאירה את האוגר מסוחרר וקשה לשליטה לזמן קצר. נפילה גבוהה, ירידה מהמסלול או מכשול קטלני מחזירים כדור חדש למסלול אחרי השהיה | כן: מצב "מסוחרר" + ריספון בצ'קפוינט |
| **צ'קפוינטים בלתי נראים** | ריספון בצ'קפוינט הקרוב, ואותם צ'קפוינטים בכל המצבים | כן, אבל גלויים (טבעת כחולה). עדיף ל־UX |
| **ניקוד** | הזמן שנשאר ×100, ועוד 1000 נקודות על ניצחון זמן ה־par | כן |
| **Time Trial** | מדליות ארד, כסף וזהב, ומעליהן גביע "Golden Weasel" | כן, עם דרגה רביעית משלנו: **בלוט הזהב** |
| **בונוסי זמן מוסתרים** | ב־Up Race כפתור אדום גדול ליד הקו נותן 5 שניות בונוס | כן: כפתור +5 |
| **Mirror Tournament** | נפתח אחרי סיום הטורניר | אפשרי בהמשך (היפוך X של הדאטה) |
| **Rodent Rumble** | עד 4 שחקנים, צריך להפיל את היריבים מהזירה | אחרי ה־MVP |

## מכשולים ואלמנטים במקור, והמקבילות המקוריות שלנו
| במקור | מה עושה | אצלנו |
|---|---|---|
| Bumpers | נדלקים ומעיפים את הכדור במהירות, לפעמים מהצוק | `bumper` |
| Pipes / Tubes | הובלה בטוחה וארוכה, בעיקר אנכית | `tube` |
| Vacuums | "צינור הפוך" ששואב למעלה | `lift` |
| Catapults | זורקים את הכדור מעל פערים | `launcher` + `gap` |
| Buzzblades | שוברים את הכדור וגם חותכים חלקים מהמסלול | `saw` + אריחים מתפוררים (`collapse`) |
| Sawguys | רק מסחררים | אפשר כווריאנט של `saw` |
| 8-Ball | כדור יריב שמנסה להפיל אותך (בונוס 2000 אם מפילים אותו) | `rival` (עם עיצוב משלנו) |
| Speed cylinders / Elevators | האצה וקומות | `speedpad`, `lift` |
| Windmill / Drawbridge / Hammer | מכשולים מתוזמנים | `spinner`, `mover`, `hammer` |
| Tar | מאט | משטח `tar` |
| Neon / Glass | ערכות נושא | ערכות `neon` ו־`ice` / משטח `glass` |

## עקומת קושי
לפי המקור: Tower ו־Up קלים עד בינוניים, Neon בינוני, ו־Expert "ינצח אותך בפעם הראשונה". יש בו גם שלוש רמות קושי (Pipsqueak, Normal ו־Frenzied) שמשנות את הזמן שמקבלים. **אצלנו** יש 8 מרוצים בקושי עולה: שניים ללימוד, ארבעה שכל אחד מציג מכניקה חדשה, ושני גמרים שמשלבים הכול. יש גם 3 רמות קושי שמכפילות את `raceTime` ב־×1.3, ×1.0 ו־×0.75.

## מה *לא* לוקחים (זכויות יוצרים)
השם Hamsterball, הלוגו, השמות Raptisoft, 8-Ball ו־Golden Weasel, מבני המסלולים המקוריים, המוזיקה (Peter Hajba) והגרפיקה לא נכנסים. המכניקות, כלומר כדור, שעון, מכשולים ומדליות, הן רעיונות ג'אנר ואפשר להשתמש בהן. המותג, הדמות (פיצי), המסלולים, הסאונד והטקסטורות בחבילה מקוריים כולם.

## החלטות עיצוב ל־PITZI ROLL
1. **מצלמה בזווית קבועה** (איזומטרית למחצה, עוקבת ולא מסתובבת), כמו במקור. השליטה תמיד יחסית למסך, וזה חוסך את הבלבול של מצלמה מסתובבת.
2. **המסלולים הם דאטה ולא מודלים**: שרשרת סגמנטים (ישר, עיקול, פלטפורמה, פער, צינור, מעלית) ב־`levels.json`. המנוע בונה את הגיאומטריה ואת הקוליז'ן, ומוסיפים מסלול בלי לגעת בקוד.
3. **Three.js + Rapier (WASM)**: כדור על trimesh, גופים קינמטיים לפלטפורמות נעות ו־CCD נגד "מנהור" במהירות גבוהה. כל ה־API נבדק בבדיקת עשן.
4. **ממשק בעברית RTL כברירת מחדל**, עם מתג EN (לראיונות).
5. **המשחק חי ב־HEN'S ARCADE** ומשתמש באותה שפה ויזואלית: אינדי־ארקייד פרימיום, צבעוני ונקי.
